# Lost & Found – Campus Portal

Lost & Found is a responsive, frontend-only campus website that helps students report lost belongings and browse items reported as lost or found within the campus.

## Features
- Submit reports for lost or found items.
- Browse available lost and found listings.
- Search and filter reported items.
- View item details.
- Delete listings when they are no longer needed.
- Save reports automatically using browser LocalStorage.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage

## How to Run
1. Download or clone the project repository.
2. Open the `lostandfound` folder.
3. Open `index.html` in a web browser.
4. Alternatively, use the VS Code Live Server extension.

## Deployment
Lost & Found can be deployed independently using Vercel.

- Framework Preset: Other
- Build Command: Leave blank
- Output Directory: `.`

## Project Type
Frontend-only web application. No backend or database is required. Reports are stored locally in the user's browser and are not shared with other users or devices.
